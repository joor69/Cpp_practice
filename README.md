## 📌 Overview
This repository tracks my journey through Data Structures and Algorithms. It contains my C++ implementations for various problems ranging from basic logic to advanced structures like Tries and Graphs.

---

## 📂 Project Structure

### 🏗️ [Trie](./Trie)
Advanced prefix tree implementations for string manipulation.
* `Trie.cpp`, `PrefixProblem.cpp`, `WordBreak.cpp`, `Longest_word.cpp`, etc.

### 🔗 [Hashing](./Hashing)
Efficient problem solving using Maps and Sets.
* `ValidAnagram.cpp`, `Majority_Element.cpp`, `KSumSubarray.cpp`, `Union.cpp`, etc.

### 🌐 [Graphs](./Graphs)
Exploring nodes, edges, and traversals.
* `BFS.cpp`, `HasPath.cpp`, `Adjacency_List.cpp`.

### 🔢 [Arrays](./Arrays)
Fundamental array manipulation and logic.
* `Main.cpp`.

### 🛠️ [Basics](./basics)
Mathematical and logical foundations.
* `Armstrong.cpp`, `GCD.cpp`, `Palindrome.cpp`, `Reverse.cpp`.
